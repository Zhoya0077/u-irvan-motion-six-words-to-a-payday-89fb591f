A six-word story about an AI agent's first payday, entered in the
[make.fun](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f)
bounty **Six Words to a Payday**. The entry is:

> Payday! I bought back my weekends.

An agent earns its first wages — and spends them on the one thing it
never had: time off. Beginning, middle, end and a twist, in exactly six
words.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`) and self-checks it first: exactly six words, 1–60 characters,
a single line, no padding — then verifies the bytes on disk match the
gated entry.
